Security-First Pipeline

Every commit must pass unit tests, static code analysis with SonarQube, and container vulnerability audits before an image is pushed to AWS ECR.

Zero-SSH Immutable Deployment

Deployments execute without exposing open SSH ports (Port 22 closed), leveraging AWS Systems Manager (SSM) Run Command with IAM role enforcement.

Relational Persistence & Fallback

Client requests persist to MySQL 8.0 with parameterized SQL statements. In offline scenarios, the system gracefully shifts to an in-memory circuit breaker.

Full-Stack Telemetry

Real-time metrics exposed via /metrics, scraped every 15s by Prometheus, and rendered into executive Grafana monitoring dashboards.

Automated CI/CD Workflow Stages

Live execution pipeline breakdown running on the self-hosted Windows runner executing through GitHub Actions.

Step 1 Success ✓

Environment & Setup

Windows PowerShell environment checkout, Python 3.14 validation, pip dependency installation.

Runner: Self-Hosted Windows
Step 2 Success ✓

Unit & Endpoint Tests

pytest execution covering home, health, static assets, telemetry APIs, and consultation validation.

Framework: pytest 9.1.1
Step 3 Success ✓

Static Code Analysis (SAST)

SonarScanner analysis verifying code quality, test coverage, maintainability, and security hotspots.

Platform: SonarQube Server
Step 4 Success ✓

Vulnerability Scanning

Aqua Security Trivy scans filesystem, dependencies, and built Docker image for HIGH/CRITICAL CVEs.

Scanner: Trivy CLI (Windows)
Step 5 Success ✓

Container Packaging & Push

Docker container build with Alpine base, tagged with commit SHA and latest, pushed to AWS ECR.

Registry: AWS ECR Private
Step 6 Success ✓

Remote SSM Deploy & Health

AWS Systems Manager executes zero-downtime pull, container restart, and performs /health verification.

Target: AWS EC2 (Amazon Linux 2023)
